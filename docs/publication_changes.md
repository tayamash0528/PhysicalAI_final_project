# 公開準備で変更したもの

採用済みのVLA・再観察・シーン・判定の実装、C1250、比較条件、正式40試行の結果は変更していない。性能調整・追加学習・本比較の再実行も行っていない。

- README・再現手順・確認記録を、配布候補と実行済みの検証に合わせて更新した。
- 配布手順、release_manifest.json、URL未設定のrelease_urls.json、出典・ライセンス通知を整備した。
- tools/publication/へ、配布ZIPの検証・配置、固定上流の取得、モデル・アセット準備、主要依存検査、既知配置デモ、静的検証の補助コードを追加した。採用run_rollout.pyのaction経路は変更していない。
- processorを固定revisionへ取得後、そのrevisionを採用repo名のローカル参照からも解決する準備処理を設けた。実行中に別視点や別モデルへ置き換える処理ではない。
- 公開候補では.gitattributesで改行変換を無効にし、採用LOCKが記録するバイト列のSHAを維持する。キャッシュ・重み本体・出力をGitへ加えない.gitignoreを配置した。

元のREADME・再現文書・通知と変更前のSHA一覧はローカルの公開準備フォルダーに退避した。元フォルダー全体はGit管理されていなかったため、公開候補には過去のGit履歴を捏造せず、新しい未コミット作業領域だけを作成した。個人の氏名・メールをGitコミットへ設定していない。

録画・JSONL・画像・大容量教師データは元の実験ディレクトリで保持し、公開候補へは固定条件、CSV、集計JSON、試行別の小容量result.json、学習系譜のメタデータを収録した。以前のsource review ZIPも上書きしていない。

ライセンス原文・上流モデルカードなど引用元の文書は原文を維持し、自作の説明文書は日本語で作成した。[確認記録](readme_validation.md)に検証済みの範囲と残作業を記載する。
