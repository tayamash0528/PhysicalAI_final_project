## 未確認範囲と固定版

- 40stepは20Hzの制御区間として2秒相当。最初と最後の観測時刻差は1.95秒で、サンプル間・MuJoCo全substepの厳密連続2.000秒を独立に保証するログはない。既定の離散判定を維持し、今回値を変更しない。
- 高さ50mm境界や指の同時接触は動画だけでは厳密判別できず、数値はMuJoCoログによる。全頂点の内包は実行時booleanと判定コードで確認したが、毎stepの果実姿勢を保存していないため頂点位置の独立再計算はできない。
- 動作後の厳密な正規化可視率は従来どおり品質不合格。初期40画像一致、動作後0/40一致。実画像の遮蔽軽減と操作の因果は別扱い。

全20の監査データは [predicate_review](predicate_review/README.md)、各該当試行の最終40stepは同フォルダーのCSV。元データ・元集計・旧ZIPは保存し、今回の採用候補と確認資料は別管理。追加の操作実行は不要と判断し、行っていない。
